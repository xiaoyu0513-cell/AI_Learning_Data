LangGraph Runtime 运行图

理解 Node · Edge · State 三要素与 Superstep 执行机制

一个简单的 线性图：START → node_1 → node_2 → END。每个节点读取当前 State，执行业务逻辑，返回对 State 的局部更新。右侧面板记录真实 checkpoint 快照；END 是终止边界，不会产生额外的节点执行快照。

运行时三要素 —— 点击下方按钮，依次查看各要素在图中的位置与作用。

① 路由 ② 执行 ③ 提交
① 路由阶段（Plan / Routing）：根据当前 State 和 Edge 逻辑，确定本轮应执行的节点。
node_1 执行完毕，出边指向 node_2，node_2 被选中为下一轮执行节点。
绿色：已执行完毕 黄色：正在处理

Checkpoint 快照序列 —— 按历史记录还原 metadata.step、next 与 State。节点执行结果会出现在对应快照的 tasks.result 中。
